# estoquelab
Sistema de controle de estoque de reagentes para laboratórios usando Python e Streamlit.

## Funcionalidades
- Cadastro de reagentes com lote, quantidade e status
- Retirada de reagentes com exclusão automática ao zerar
- Dashboard com cores no status
- Integração com Google Sheets

## Tecnologias
- Python
- Streamlit
- Pandas
- gspread / Google Sheets API
